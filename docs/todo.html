Simple Todo

This page ships a disabled HTML skeleton and three plain-text .go files. On load, GoScript fetches the source, compiles and links it with the real Go toolchain in your browser, runs the WebAssembly, and only then does the Go program attach every event listener and enable the controls.

Page-load pipeline

Each step runs in your browser, in order. The page has no JavaScript for the todo logic.

  1. Fetch .go sourceswaiting
  2. Load Go toolchainwaiting
  3. Compile & linkwaiting
  4. Run the WASMwaiting
  5. Go attaches listenerswaiting
