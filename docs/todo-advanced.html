Advanced Todo

A full task manager written entirely in Go: projects, tags, priorities, due dates, a search language, undo and redo, statistics, keyboard shortcuts, and JSON import and export. The HTML page contains only an empty <div id="app-root">. Go builds the interface, injects its own CSS, and attaches every listener after it is compiled in your browser.
